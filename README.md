Build a premium, modern, professional MULTI-PAGE personal portfolio website for:

Prajakta Inamke

Web Developer | Freelance Web Developer | Web Solutions Specialist

IMPORTANT:

This must be a true MULTI-PAGE website with separate routes/pages.

DO NOT create a one-page scrolling portfolio.

DO NOT simply hide/show sections on the homepage.

Required routes:

/

/about

/services

/portfolio

/portfolio/:slug

/experience

/contact

PRIMARY GOAL

The website should position Prajakta as an experienced professional web developer who can independently handle complete website and web application projects.

The primary conversion goal is:

→ Get freelance project enquiries

→ Build trust with potential clients

→ Showcase real development capabilities

→ Convert LinkedIn visitors into leads

The website should NOT look like:

- a student portfolio

- a resume template

- an AI-generated landing page

- a generic developer portfolio

- an overly dark hacker/coding website

It should feel like a premium digital professional / independent web consultant website.

DESIGN DIRECTION

Create a clean, elegant, modern and premium UI.

Use:

- Light theme as primary theme

- White / warm off-white backgrounds

- Deep charcoal typography

- One sophisticated accent color

- Generous whitespace

- Premium typography

- Subtle gradients where appropriate

- Soft shadows

- Elegant cards

- Large headings

- Clean grids

- Modern image layouts

- Smooth micro-interactions

- Subtle scroll animations

Avoid excessive:

- gradients

- glassmorphism

- neon colors

- glowing buttons

- floating blobs

- random illustrations

- excessive rounded cards

- developer clichés

- AI-looking graphics

The website should feel handcrafted.

Use high-quality professional imagery/placeholders where necessary.

Do not fill every section with stock images.

RESPONSIVE DESIGN

Design desktop, tablet and mobile layouts carefully.

Do not simply shrink desktop layouts.

Mobile must have:

large readable typography

touch-friendly CTAs

optimized portfolio cards

optimized forms

---

FUNCTIONAL REQUIREMENTS

Use React.

Use proper reusable components.

Implement React Router or the routing system already available in the project.

All navigation links MUST navigate to actual routes.

All CTA buttons must work.

Portfolio filters must work.

Project detail routing must work.

Contact form validation must work.

Mobile menu must work.

Test every route.

Do NOT leave dead buttons.

Create clean reusable data structures for projects, services and experience so content can easily be changed later.

---

ANIMATION

Use tasteful animations only.

Examples:

fade/slide reveal

project image hover

subtle button interaction

navigation transitions

text reveal

Animations should feel premium and professional, not flashy.

---

FINAL QUALITY CHECK

Before completing the project:

1. Verify this is a true multi-page website.

2. Verify every navigation item has its own route.

3. Verify portfolio project detail pages work.

4. Verify all buttons have actions.

5. Verify responsive behavior.

6. Remove placeholder lorem ipsum.

7. Remove obvious AI-generated copy.

8. Avoid repetitive card-based layouts.

9. Ensure visual hierarchy is consistent.

10. Make the website look credible enough that a business owner visiting from LinkedIn would feel comfortable sending a project enquiry.

The final result should feel like the personal website of an experienced independent web developer and web consultant, not a beginner portfolio.
