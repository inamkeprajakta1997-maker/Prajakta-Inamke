# Live project previews

captured on October 22, 2026. They are bundled locally so visitors do not depend
on an external screenshot service or load the project websites inside iframes.

To refresh a preview, open the source at a desktop viewport, allow its content
to load, dismiss any modal using its close control, and capture the first
viewport. Export a JPEG at this size with moderate compression and replace the
matching asset. Do not substitute stock imagery or fabricated website mockups.
Update the capture date here when replacing the images. Project copy and image
alt text live in `src/lib/portfolio-data.ts`.
